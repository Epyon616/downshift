# Portfolio – Lee

A personal portfolio built with React and TypeScript, focused on clean UI, performance, and maintainable frontend architecture.

## Overview

This project serves as a central place to showcase my work, technical approach, and frontend engineering capabilities.

Rather than relying on heavy UI frameworks, the application is built with a focus on simplicity, composability, and performance.

### Tech Stack

```
React
TypeScript
Vite (SWC)
SCSS
```

### Key Focus Areas

Component architecture
Small, reusable components with clear separation of concerns.
Performance
Fast load times via Vite and minimal runtime overhead.
Maintainability
Straightforward structure with predictable patterns and minimal abstraction.
UI/UX clarity
Clean, distraction-free presentation of projects and content.

### Project Structure

```
src/
  Assets/
  Components/
  Conf/
  Sass/
  Sections/
```

### Getting Started

```
pnpm install
pnpm dev
Build
pnpm build
pnpm preview
```

This project is intentionally lightweight. The goal is to highlight:
